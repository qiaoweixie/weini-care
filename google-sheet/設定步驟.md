# 表單接 Google 試算表｜設定步驟

網站的預約表單與聯絡表單，送出後會寫進同一份 Google 試算表的兩個工作表（「預約」與「聯絡」），並寄一封通知信。做法是把 `Code.gs` 貼進試算表的 Apps Script，部署成網頁應用程式。整個過程約 10 分鐘，只需要做一次。

## 1. 建立試算表

1. 用 qiaoweixie@gmail.com 登入 Google，到 https://sheets.new 建一份新試算表。
2. 命名為「午睡空間｜表單」。工作表不用先建，程式第一次收到資料時會自動建立並加上標題列。

## 2. 貼上程式

1. 在試算表上方選單點「擴充功能」→「Apps Script」。
2. 把編輯器裡原本的內容全部刪掉，貼上 `Code.gs` 的全部內容。
3. 最上方 `NOTIFY_EMAIL` 是收通知信的信箱，預設是 qiaoweixie@gmail.com，要改就改這一行。不想收信就改成 `''`。
4. 按 Ctrl + S 儲存，專案名稱隨意，例如「表單寫入」。

## 3. 部署成網頁應用程式

1. 編輯器右上角「部署」→「新增部署作業」。
2. 左邊齒輪選「網頁應用程式」。
3. 設定：
   - 說明：隨意
   - 執行身分：**我**
   - 誰可以存取：**所有人**（一定要選這個，網站訪客才送得進來）
4. 按「部署」。第一次會要求授權：選你的帳號 → 「進階」→「前往（專案名稱）（不安全）」→「允許」。這是 Google 對自己寫的程式的固定警告，不是真的不安全。
5. 複製「網頁應用程式網址」，格式像：
   `https://script.google.com/macros/s/AKfycb.../exec`

## 4. 貼到網站

1. 打開 `index.html`，搜尋 `SHEET_ENDPOINT`。
2. 把網址貼進單引號中間：
   ```js
   var SHEET_ENDPOINT = 'https://script.google.com/macros/s/AKfycb.../exec';
   ```
3. 存檔、push。

## 5. 測試

1. 在線上網站填一次預約表單送出，應該看到「收到了」。
2. 回到試算表，「預約」工作表會多一列，信箱會收到通知信。
3. 聯絡表單也送一次，確認「聯絡」工作表有資料。

## 之後改程式怎麼辦

改了 `Code.gs` 之後要重新部署才會生效：「部署」→「管理部署作業」→ 鉛筆圖示 → 版本選「新版本」→「部署」。網址不會變，網站不用改。

## 常見問題

**送出後顯示「暫時送不出去」**
先在瀏覽器直接打開網頁應用程式網址，看到 `{"result":"ok",...}` 代表服務正常，問題在網址貼錯。若看到要登入的畫面，代表「誰可以存取」沒有選「所有人」。

**通知信沒收到**
看垃圾郵件。Apps Script 免費帳號每天可寄 100 封，一般用量足夠。

**想知道每列的處理進度**
試算表有「處理狀態」欄，新資料預設是「待處理」，你可以自己改成「已確認」「已完成」之類，程式不會動它。
