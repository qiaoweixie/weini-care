# 有照片版｜等實拍照到位後改回這一版

備份日期：2026-09-17

這一版的版面預留了 5 張實拍照片的位置：

| 檔名 | 用途 | 建議尺寸 |
|---|---|---|
| `placeholder-hero.svg` | 首屏主視覺 | 直式 4:5，960×1200 以上 |
| `placeholder-story.svg` | About 區直式照 | 直式 4:5，960×1200 以上 |
| `placeholder-space-large.svg` | Space 區全景 | 橫式 4:3，1200×900 以上 |
| `placeholder-space-bedding.svg` | Space 區寢具細節 | 橫式 4:3，960×720 以上 |
| `placeholder-space-light.svg` | Space 區光線角落 | 橫式 4:3，960×720 以上 |

目前線上版（專案根目錄）因為沒有照片，改成：
首屏用巧薇去背照、About 用品牌色圖形、Space 改成資訊卡、Founder 只留文字。

## 還原步驟

1. 把實拍照轉成 WebP，放進 `assets/images/`。
2. 把這個資料夾的 `index.html` 覆蓋回專案根目錄，`assets/css/site.css` 覆蓋回 `assets/css/`。
3. 在 `index.html` 把 5 個 `placeholder-*.svg` 換成實拍照檔名，`width`／`height` 改成實際尺寸。
4. Founder 區塊的 `founder.webp` 已在這版裡，不用動。
5. 本機預覽確認後 push。

注意：這個備份是 2026-09-17 的狀態。若之後根目錄的 `index.html` 有改文字、連結或表單，
還原時要把那些改動一起搬過來，最簡單的方法是用 VS Code 的檔案比較功能對照兩個檔案。
